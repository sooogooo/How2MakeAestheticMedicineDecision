## 一、吸脂按吸脂量分级

《医疗美容项目分级管理目录》（卫办医政发〔2009〕220 号）把美容外科项目分四级。脂肪抽吸术按吸脂量定级。

| 吸脂量 | 级别 |
| --- | --- |
| 小于 1000 毫升 | 一级 |
| 1000 到 2000 毫升 | 二级 |
| 2000 到 5000 毫升 | 三级 |

分级依据是手术难度、复杂程度和可能出现的医疗意外与风险大小。

## 二、机构能做几级

| 机构条件 | 能做的级别 |
| --- | --- |
| 设医疗美容科或者整形外科的一级综合医院和门诊部；设医疗美容科的诊所 | 一级 |
| 设医疗美容科或者整形外科的二级综合医院；设麻醉科及医疗美容科或者整形外科的门诊部 | 一、二级 |
| 美容医院 | 一至三级 |
| 三级整形外科医院；设医疗美容科或者整形外科的三级综合医院 | 一至四级 |

二级项目写明的条件是「需使用硬膜外腔阻滞麻醉、静脉全身麻醉等完成」。三级项目写明的条件是「需气管插管全麻」。

来源：卫生部办公厅《医疗美容项目分级管理目录》（卫办医政发〔2009〕220 号）。各省可以在此基础上调整，山东、四川、海南等省已发布地方版目录。

**怎么用：** 问一句「这次吸多少毫升」，再对机构的级别。做超出级别的项目属违规。

## 三、死亡数据

这一节的数据来自尸检和死亡普查。它们说的是死因分布，不是总体死亡率。

### 伊斯坦布尔尸检研究（2022—2024）

35 例吸脂相关死亡。

| 项目 | 数字 |
| --- | --- |
| 女性 | 100% |
| 平均年龄 | 41.7 岁 |
| 平均 BMI | 29.5 |
| 多术式 | 85.7% |
| 其中腹壁成形 | 94.3% |
| 其中乳房成形 | 57.1% |
| 其中臀部脂肪移植 | 54.3% |
| 肺血栓栓塞 | 65.7% |
| 深静脉血栓 | 40.0% |
| 肺水肿（组织病理） | 71.4% |
| 肺脂肪栓塞（组织病理） | 68.6% |
| 术中恶化与臀部脂肪注射有关 | 5 例 |

来源：Liposuction associated fatalities in Istanbul from a forensic perspective: An autopsy study. PMID 41172581. <https://pubmed.ncbi.nlm.nih.gov/41172581/>（题录待补全）

### 美国吸脂死亡普查

Grazer 和 de Jong 的调查给出约每 10 万例 19.1 例死亡。已知死因排序：肺血栓栓塞 23.1%；腹部和内脏穿孔 14.6%；麻醉、镇静、药物 10%；脂肪栓塞 8.5%；心肺衰竭 5.4%；感染 5.4%；出血 4.6%。

**读这些数字时注意三件事：**

1. **尸检病例只是死亡中的一部分。** 吸脂相关死亡并非必须尸检，所以实际死亡数可能被低估。
2. **普查数据是 2000 年前后的。** 麻醉方式和操作规范此后有变化。
3. **不同来源的分母不一样。** 有的按手术例数，有的按调查回执数，不能直接相加。

## 四、风险因素

文献里反复出现的风险因素：

- 高 BMI
- 多术式联合
- 臀部脂肪移植或者注射
- 腹壁成形术
- 全麻超过 30 分钟
- 手术超过 2 小时
- 去除脂肪量过大
- 年龄大于 60 岁
- 脱水
- 静脉曲张
- 口服避孕药
- 吸烟
- 遗传性高凝状态

## 五、麻醉

麻醉是吸脂死亡的主要环节之一。美国那份普查里，麻醉、镇静、药物一项占死因的 10%。

分级目录把麻醉方式和机构级别绑在一起：

- 二级项目需要硬膜外腔阻滞麻醉或者静脉全身麻醉。
- 三级项目需要气管插管全麻。
- 门诊部要做二级项目，条件之一就是设有麻醉科。

**怎么用：** 面诊时问三句。

1. 谁麻醉，什么职称。
2. 场所里有没有抢救设备和除颤仪。
3. 出事往哪家医院转，谁陪同。
