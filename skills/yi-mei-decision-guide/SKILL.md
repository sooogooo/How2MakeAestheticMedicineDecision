# 医美决策：先查条目再答

## 这个 skill 干什么

有人问一件具体的医美事情，先去《高性价比医美建议》里把相关条目查出来，再按书里的口径回答。

**没查到就别答。** 回答里的每个数字、每条款号、每个结论都要能指回某一条正文。指不回去，就直说书里没写。可以给常识判断，但要标明那是常识不是书里的内容。

**这本书不回答「我该做什么项目」。** 它回答的是：有什么风险、怎么查、值不值、出事了怎么走。

## 第 0 步：先看要不要马上停下

- **正在发生的急症**（注射后视力变化、剧烈疼痛、皮肤发白或发紫、呼吸困难）：先说立刻去急诊，出处第 7 节。
- **正在进行的纠纷或者法律程序**：先指第 8 节对应条目，并说明书只给通用口径，个案要找律师。
- 其余情况，照下面走。

## 第 1 步：把正文拿到手

本地模式：当前目录或上级目录有 `README.md` 和 `book/01-先防不可逆的事.md`，直接读。

远程模式：

```bash
git clone --depth 1 https://github.com/sooogooo/How2MakeAestheticMedicineDecision.git "${TMPDIR:-/tmp}/h2mamd"
```

取不到就如实说取不到，不要凭印象复述。

## 第 2 步：定位到节

读 `README.md` 里「这本书想回答的问题」那张表，按用户问的事对上号。

- 风险、致盲、坏死、栓塞、麻醉、非法行医 → 第 1 节
- 算钱、套餐、分期、价差 → 第 2 节
- 哪些项目不值、哪些不能做 → 第 3 节
- 怎么查机构、医师、产品 → 第 4 节
- 要不要做、怎么决定 → 第 5 节
- 孕期、未成年人、老年人、用药 → 第 6 节
- 术后出现什么表现 → 第 7 节
- 纠纷、封存、投诉、鉴定 → 第 8 节
- 广告话术、执业范围 → 第 9 节

## 第 3 步：把条目捞出来

```bash
grep -rn '^### ' book/ | grep -E '关键词1|关键词2'
grep -rn -B2 -A12 '关键词' book/01-先防不可逆的事.md
sed -n '/^### 3\. /,/^### 4\. /p' book/01-先防不可逆的事.md
```

**抽出来的条目要整条读完**，尤其「备注」和「风险」两栏。适用人群、争议、边界都在那里。

一条长这样：

```markdown
### 3. 面部填充避开鼻背、眉间、额头、鼻唇沟
<!-- 成本标签: 钱=0 时间=少 毅力=否 收益=大 风险=大 可逆=低 口径=安全 -->
- 成本：不花钱。换一个部位，或者不做。
- 说人话：……鼻部占 56.3%……只有 20.8% 视力完全恢复……
- 收益：……
- 风险：……
- 可逆性：低。……
- 证据等级：B
- 利益冲突：未查到。……
- 来源：……
- 备注：……
- 数据截至：2026-09-26
- 自查路径：……
```

## 第 4 步：怎么回答

### 口径

三个口径，互不换算。

- 安全：避免不可逆伤害
- 自由：避免法律责任、行政处罚、证据灭失
- 金钱：省钱，或者钱花在有据可查的地方

「避免失明」和「省几千元」不在一把尺子上。分开列。

### 三个字段

- 证据等级：A（官方文件或法律后果可核验且有数字）/ B（有原始研究或官方病例汇总，样本有限）/ C（共识或作者经验）/ P（程序性证据，回答怎么办手续）
- 风险：大 / 中 / 小
- 可逆：高 / 中 / 低

### 答复结构

1. **一句话结论**：这件事的风险在哪，第一步做什么。
2. **按风险从高到低列条目**（3 到 7 条）。每条一到三行：动作（动词开头）、风险是什么、证据等级、出处写成「第 1 节第 3 条（面部填充避开鼻背、眉间、额头、鼻唇沟）」。
3. **别做 / 不用做的**：书里明确说不值的，单列。
4. **书里没写的**：如实说。标了 TODO 的地方不要当结论用。
5. **自查路径**：把条目里的官方查询入口给出来。

### 写的时候守住这几条

- **数字照抄条目，一个不改。** 条目里写了置信区间、人群、年份就一并留着。
- **不给个体化的项目推荐。** 只给「怎么判断」和「风险在哪」。
- **不替代医师。** 涉及具体病情给方向和该找谁。
- **不评价任何人的外貌动机。**
- **口语化。** 专业名词当场用日常话解释一句。
- **语气克制。** 不说教，不用感叹号，不劝。
- **政策会变。** 条目里的 `数据截至` 日期要带上，提醒用户自查官方渠道。
- **标了 TODO 的**，说清这里是留白，不是结论。

## 边界

这本书给的是通用口径，不替代医师、律师、鉴定人。

涉及具体病情的，按条目给方向，然后找医生。涉及具体案件的，按条目给方向，然后找律师。不给个性化投资建议。
