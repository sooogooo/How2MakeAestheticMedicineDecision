## 怎么读

- **先读第 1 节和第 4 节。** 第 1 节防不可逆的事。第 4 节教你怎么查。这两节不需要医学背景，一个下午能做完。
- **第 2 节只给算账方法，不给项目排名。** 理由：按性价比给项目排名，会把便宜、快、效果立现的项目排在前面，而其中一些正是不良反应最高发的部位。
- **排序不按性价比。** 先按风险分层，层内才排性价比。见下面「排序规则」。
- **不同口径不互相比较。** 「避免失明」和「省几千元」不在一把尺子上。
- **有 13 处 TODO。** 这些地方没找到可逐字核对的官方原文或者完整题录，所以留白。不要把标了 TODO 的地方当结论用。
- **「说人话」一行只用「收益」「风险」两栏已经写到的内容。** 不添新数字。只看这一行就够拿主意。

## 五个口径

每条只归一个口径。不同口径之间不做比较。

| 口径 | 换回什么 | 条数 |
| --- | --- | --- |
| 安全 | 避免不可逆伤害（失明、坏死、栓塞、致残、死亡） | 52 |
| 自由 | 避免法律责任、行政处罚、证据灭失 | 20 |
| 金钱 | 少花钱，或把钱花在有据可查的地方 | 16 |

另有「效果确定性」和「可逆性」两个维度，写在条目字段里，不单列口径。

## 证据分级

| 等级 | 判据 | 条数 |
| --- | --- | --- |
| A | 官方文件或法律后果可核验，且有具体数字 | 27 |
| B | 有原始研究或官方病例汇总，但样本有限、无对照、或终点主观 | 17 |
| C | 行业共识或作者经验，没有可引文献 | 18 |
| P | 程序性证据：回答怎么办手续、怎么查验、出事走哪条路 | 26 |

P 是这本书新增的一档。它管的不是「有没有效」，是「合不合法、能不能查」。第 4 节十条全是 P。

**疗效类条目必须写明证据天花板。** 例：埋线提升做不出假手术对照的随机试验，所以这类结论的上限就是病例系列。理由不是研究者不努力，是伦理上做不出来。这类话写在备注里。

## 排序规则

分三层。

1. 按风险分层。风险大的排前面，不管性价比。
2. 层内按性价比排。
3. 同档按证据等级 A > B > C > P。

第一层的理由：按性价比排，玻尿酸填充鼻背会排在前面。它便宜、快、效果立现。它也是致盲最高发的部位。汇总的注射后失明病例里，鼻部占 56.3%，只有 20.8% 视力完全恢复。

## 前言：这本书证明不了什么

这五条决定本书的边界。写在最前面。

1. **多数术式做不出假手术对照。** 所以效果类结论的证据上限是 B。这不是研究者的疏忽，是伦理限制。
2. **美观是主观终点。** 没有统一量表。患者报告结局受术前期待影响。
3. **利益冲突无处不在。** 连「专家共识」也常由厂家或者术式发明人牵头。本书每条标资助方、作者身份、研究中心数量。查不到就写「未查到」。
4. **发表偏倚更严重。** 成功案例发论文，失败案例进法院、进投诉、进修复门诊。所以病例系列里的有效率偏高，并发症率偏低。
5. **不可逆性是医美最该讲、最少讲的一维。** 能溶解不等于能救回。能取出不等于能复原。

## 术语表

| 术语 | 意思 |
| --- | --- |
| 三类医疗器械 | 风险等级最高的一类医疗器械。注射类填充物按这一类管理，要取得国家药监局注册证 |
| 注册证 | 医疗器械或者药品批准上市的证明文件。上面写有「适用范围」，也就是批准用在哪些部位、哪些用途 |
| 适用范围 | 注册证上写明的批准用途。用在范围之外，就是用在了没批的地方 |
| 主诊医师 | 具备《医疗美容服务管理办法》第十一条条件、负责实施医疗美容项目的执业医师 |
| 主诊医师负责制 | 医美项目要由主诊医师负责，或者在其指导下实施 |
| 医疗美容 | 运用手术、药物、医疗器械以及其他具有创伤性或者侵入性的医学技术方法，对人的容貌和人体各部位形态进行的修复与再塑 |
| 生活美容 | 不破皮的护理类服务。它不属于医疗行为，不能做破皮项目 |
| 血管栓塞 | 注射物进入血管，随血流堵住远端血管。堵在视网膜动脉会造成失明，堵在皮肤血管会造成坏死 |
| 透明质酸酶 | 能分解透明质酸（玻尿酸）的酶。用于溶解玻尿酸。对已经造成的视网膜缺血基本无效 |
| 可逆性 | 做完能不能撤、什么时候撤、撤了剩什么 |
| 躯体变形障碍 | 把一个别人基本看不出来的缺陷放大到影响生活，反复检查、反复不满意 |
| 吸脂量分级 | 《医疗美容项目分级管理目录》按吸脂毫升数把脂肪抽吸术分级的制度 |
| 封存 | 医患双方在场，把病历或者现场实物封起来、开清单、各执一份。用于固定证据 |
| 标准化死亡比 | 英文缩写 SMR。这群人实际死了多少人，除以同年龄普通人本该死多少人。5.86 就是 5.86 倍 |
| 证据天花板 | 某类问题在方法上能拿到的最高证据等级。做不出对照试验的问题，天花板就在 B |

## 用法

- **在线筛选**：[打开在线检索页](https://sooogooo.github.io/How2MakeAestheticMedicineDecision/)。按关键词、节、证据等级、口径、风险、可逆性筛。
- **离线看**：[下载离线单文件](https://github.com/sooogooo/How2MakeAestheticMedicineDecision/releases/download/offline-latest/HowToAesthetic.html)。一个文件自带全部正文，双击就能看，不用服务器不用联网，也能直接发给别人。链接固定不变，正文更新后自动重出。
- **自己跑**：
  - 起服务器：`python -m http.server 8000`，然后开 `http://localhost:8000/`。直接双击 `index.html` 会空白（浏览器不许网页读本地文件）。
  - 打离线包：`node tools/offline.mjs`，产物在 `dist/`。
  - 校验结构：`node tools/verify.mjs`。会查标签字段、栏位缺失、说人话长度、说人话里有没有混进行话。
- **只想看风险最大的**：筛「风险 = 大」，得到 29 条。
- **只想看不可逆的**：筛「可逆 = 低」，得到 29 条。
- **只想看能立刻做完的**：筛「钱 = 0」且「时间 = 少」，得到绝大部分条目。

## 局限

这本书给的是通用口径。它不替代医师、律师、鉴定人。

- 涉及具体病情，按条目给方向，然后找医生。
- 涉及具体案件，按条目给方向，然后找律师。
- 不给个体化的项目推荐。
- 不评价任何人想改变外貌的动机。
- 政策会变。批准状态、退市、价格、资质都会变。每条标了数据截至日期和自查路径，正文不长期维护这些数字。

## 数据来源规则

- 只引原始文献和官方文件。期刊论文附 DOI 或 PubMed 链接。官方文件附文号。
- 禁引小红书、短视频、医美博主、机构自有媒体、任何二手转述。
- 数字要能在原文里找到。找不到就标「待核实」。
- 不编 DOI，不编标题，不编条款号。
- 文献链接放来源栏。备注栏不放链接。
- 每条标利益冲突：资助方、作者身份、研究中心数量。查不到写「未查到」。

## 方法论来源

本书的写作方法沿用了开源项目《高性价比人生指南》（[eternity4719/HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter)，Unlicense 公有领域）。沿用部分包括：证据分级、收益栏与说人话栏的写法、交叉引用锚点规则、条目字段结构、以及「不确定就留白」的核实纪律。

填充致盲、躯体变形障碍、神经性厌食死亡、节食与进食障碍、性激素血栓、合成代谢类固醇这几项的原始文献题录，最初由该项目核对并公开，本书重新核对后引用。

本书在原项目基础上做了三处改动：

1. 排序键从性价比换成风险分层。层内才排性价比。
2. 证据分级增加 P 档，收程序性证据。
3. 条目增加风险、可逆性、利益冲突三栏。
